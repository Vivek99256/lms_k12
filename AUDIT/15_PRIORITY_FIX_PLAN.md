## Recommended execution order (fix waves)

The P0 list contains many separate endpoints, but they collapse into a small number of root causes. Fixing the root cause once closes many rows; fixing endpoint by endpoint will not keep pace with a 3,094-route surface.

### Wave 0 - contain today (no design work, mostly config/ops)

1. **Rotate and purge committed credentials.** Inspect and rotate everything in the tracked backend env backup and the public PHP scripts, the CCAvenue working key and FCM server keys, then purge from git history: LMS-AUDIT-201, LMS-AUDIT-015, LMS-AUDIT-121, LMS-AUDIT-176. *Verify:* rotated values no longer authenticate; `git log --all` no longer contains the files.
2. **Take the anonymous data/admin endpoints offline at the web server/WAF (or add auth middleware) before any refactor:** `/table_data` + `/lms_data` LMS-AUDIT-008; `/superAdmin-store` LMS-AUDIT-046; `/api/menu-rights` LMS-AUDIT-010; `/ckeditor` and unvalidated public-path uploads LMS-AUDIT-014; `/api/crm-whatsapp` LMS-AUDIT-016 (the in-progress guard lists it as public); **`GET /api/testkey` (mints a signed JWT with no credentials) LMS-AUDIT-053 - rotate JWT_SECRET after removing it**; `/download-folder` LMS-AUDIT-047; the module dashboards LMS-AUDIT-005; anonymous LLM endpoints LMS-AUDIT-056; anonymous `/transferDocs` + `/convertDoc` (copies server directories, incl. `.env`, to a public bucket) LMS-AUDIT-050; `/unlink-file` (arbitrary file delete for any JWT) LMS-AUDIT-051; web `/import_parse` + `/import_process` LMS-AUDIT-052. *Verify:* each returns 401/404 to an anonymous request.
3. **Delete the 15 PHP scripts under `public/`** (phpinfo, request-supplied DB host, hard-coded passwords): LMS-AUDIT-015.
4. **Payments:** disable or signature-verify the ICICI/ICICI-Orange/PayPhi/AggrePay callbacks and the mobile self-receipt route until fixed: LMS-AUDIT-011, LMS-AUDIT-027.
5. **Stop leaking PII through git:** remove the tracked `.kilo/conversational-ai` state and purge history: LMS-AUDIT-059.
6. **Kill the client-chosen upstream:** make the Laravel base URL come only from server env in every Next handler and lib/agents: LMS-AUDIT-001; derive agent identity from the token, not headers: LMS-AUDIT-002.

### Wave 1 - fix the trust model (weeks 1-3)

7. **One authentication + tenant-binding layer for every Laravel route.** Put all ~90 unauthenticated controllers behind the JWT middleware and make `sub_institute_id`, `user_id`, `syear` come **only** from the token (the newly written General/UserManagement/ClassTeacher/AcademicSetup APIs are the reference implementation): LMS-AUDIT-009, LMS-AUDIT-048, LMS-AUDIT-038, LMS-AUDIT-039, LMS-AUDIT-112, LMS-AUDIT-042, LMS-AUDIT-075.
8. **Fix authorization:** remove the `submit=Search` bypass and make unmapped routes deny-by-default: LMS-AUDIT-003; add role/rights to Result, Easy-com, Organization-management, leave, import, AI console, employee directory: LMS-AUDIT-004, LMS-AUDIT-013, LMS-AUDIT-068, LMS-AUDIT-064, LMS-AUDIT-006, LMS-AUDIT-065.
9. **SQL injection programme:** bind parameters in every confirmed site and run a taint scan across all 835 controllers: LMS-AUDIT-202, LMS-AUDIT-028, LMS-AUDIT-035, LMS-AUDIT-037, LMS-AUDIT-017, LMS-AUDIT-018, LMS-AUDIT-041, LMS-AUDIT-045, LMS-AUDIT-022.
10. **Credentials model:** hash-only passwords, drop `plain_password` and `$hidden` sensitive columns, JWT expiry + revocation, login throttling, remove OTP backdoor: LMS-AUDIT-061, LMS-AUDIT-062, LMS-AUDIT-063, LMS-AUDIT-069.
11. **Public/stateless registration flows** (admissions, visitor, certificates, ID cards) need tenant binding via the school's public key or slug, not a body `sub_institute_id`: LMS-AUDIT-034, LMS-AUDIT-036, LMS-AUDIT-030.

### Wave 2 - money and marks correctness (weeks 3-6)

12. Fees: server-side amount/discount/fine computation, idempotent receipt numbering with a unique key, refund cap, gateway reconciliation: LMS-AUDIT-113, LMS-AUDIT-115, LMS-AUDIT-116, LMS-AUDIT-120, LMS-AUDIT-307, LMS-AUDIT-029.
13. Exams/results: server-side scoring, hide answer keys, enforce windows/attempts, stop the report-card zeroing bug: LMS-AUDIT-073, LMS-AUDIT-074, LMS-AUDIT-076, LMS-AUDIT-077, LMS-AUDIT-078, LMS-AUDIT-089, LMS-AUDIT-090.
14. HR: leave balance/overlap/approval rules, payroll computed and stored server-side: LMS-AUDIT-068, LMS-AUDIT-163, LMS-AUDIT-165, LMS-AUDIT-166, LMS-AUDIT-164.

### Wave 3 - safety net (parallel from week 1)

15. **CI that would have caught this:** typecheck + lint + `npm test` on every PR, fix the 2 failing tests, gate merges: LMS-AUDIT-228, LMS-AUDIT-211, LMS-AUDIT-230. Add authorization/tenant regression tests per fixed endpoint: LMS-AUDIT-054.
16. Sanitise HTML sinks with DOMPurify (shared helper) and remove `document.write` print windows: LMS-AUDIT-060, LMS-AUDIT-379; add CSP/security headers: LMS-AUDIT-229; fix CSRF wildcard host exemptions: LMS-AUDIT-057.
17. Observability and rollback: error tracking, health endpoints, deploy/rollback docs, stop signing everyone out on each deploy: LMS-AUDIT-233, LMS-AUDIT-212.
