**IconButton** — an icon-only action for toolbars, table rows and dense controls; always pass `label` (the accessible name + tooltip).

```jsx
<IconButton icon="pencil" label="Edit" />
<IconButton icon="trash-2" label="Delete" variant="danger" />
<IconButton icon="more-vertical" label="More actions" variant="ghost" />
```

Variants: `default · danger · ghost`. Sizes: `sm · md · lg`.
