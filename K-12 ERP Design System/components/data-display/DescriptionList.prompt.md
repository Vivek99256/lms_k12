**DescriptionList** — read-only labeled field values (record summaries, receipts). Canonical key/value display.

```jsx
<DescriptionList columns={2} items={[
  { term: "Admission no.", value: "ADM-2026-0421" },
  { term: "Class", value: "Grade 9 - A" },
  { term: "Guardian", value: "Meera Sharma" },
]} />
```

Variants: `two-column · inline · stacked`.
