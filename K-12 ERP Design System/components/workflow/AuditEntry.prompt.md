**AuditEntry** — an immutable "who did what, when" record for audit logs.

```jsx
<AuditEntry actor="admin@school.edu" action="Updated" actionType="update"
  target="Fee structure — Grade 9" timestamp="01 Jul, 10:24" expandable
  ip="10.0.2.14" detail={{ Field: "Tuition", From: "₹40,000", To: "₹42,000" }} />
```
